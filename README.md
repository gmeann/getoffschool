# 퇴근길 학교 (가칭)

초등 선생님을 위한 웹 기반 3D 쉼터예요. 로그인 없이 들어와서, 노을 진 운동장을 천천히 걸으며 쉬어 가는 공간입니다.

- Vite + React + TypeScript
- three, @react-three/fiber, @react-three/drei
- 서버·DB·외부 모델/텍스처 파일 없음. 모든 물체는 기본 도형으로 코드에서 만듭니다.
  (글꼴만 Pretendard(본문)·Gaegu(손글씨·분필) 웹폰트를 CDN에서 불러오고, 실패하면 시스템 글꼴을 씁니다.)

## 실행 방법

Node.js 20 이상이 필요해요. 레포를 받은 폴더에서 실행합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 열면 됩니다.

### 폰으로 접속해 보기

PC와 폰이 **같은 와이파이**에 있어야 해요.

```bash
npm run dev -- --host
```

터미널에 나오는 `Network: http://192.168.x.x:5173/` 주소를 폰 브라우저에 입력하세요.

### 빌드 / 미리보기

```bash
npm run build
```

```bash
npm run preview
```

## 조작

- 바닥을 클릭(폰은 탭)하면 캐릭터가 그 지점으로 걸어가요.
- **뛰기**: 트랙을 따라 계속 달려요. 다시 누르거나(멈추기) 바닥을 클릭하면 멈춰요.
- **앉기**: 가장 가까운 벤치(6개)나 가운데 잔디밭으로 가서 앉아요. 잔디밭 안에 있으면 그 자리에 바로 앉아요. 앉아 있는 동안 카메라가 조금 가까이 와요. 다시 누르면 일어나요.
- **하늘 보기**: 카메라가 천천히 하늘을 올려다봐요. 다시 누르거나 움직이면 원래대로 돌아와요.
- PC에서는 마우스 휠로 확대/축소할 수 있어요. 카메라 회전은 일부러 넣지 않았어요.

## 운동장 이야기

- **시간대별 하늘**: 기기 시각에 따라 오전·낮·저녁(노을)·밤으로 하늘과 조명이 바뀌어요. 시간대 사이는 부드럽게 이어져요.
- **산책하는 선생님**: 파스텔 옷을 입은 선생님 6~8명이 설렁설렁 트랙을 걷거나 뛰고, 1~2명은 벤치에 앉아 있어요. 가까이 가면 말을 걸어요.
- **걸음 카운터**: 운동장에서 이동한 거리만 트랙 한 바퀴(약 70m) 기준으로 "오늘 나는 N바퀴"로 보여 줘요. 한 바퀴마다 "한 바퀴 완주!", 10바퀴를 채우면 "운동장 10바퀴" 칭호가 생겨요.
  - 저장 위치: 브라우저 localStorage (`getoffschool:meters:날짜`, `getoffschool:titles`). 서버에는 아무것도 보내지 않아요.

## 공간 이동 (3단계)

- 공간은 한 번에 하나만 불러와요: `playground`(운동장), `office`(교무실), `classroom`(교실), `lab`(연구실). 4개 공간이 모두 열려 있어요.
- 공간 정의(이름, 배경색, 입장 위치, 문 위치, 하단 버튼)는 `src/data/scenes.ts` 한 곳에서 관리해요.
- 운동장 북쪽 학교 건물의 문(교무실·교실·연구실)을 누르면 문 앞까지 걸어가서 들어가요.
- 좌상단 "퇴근길 학교 | 공간이름"을 누르면 공간 목록이 펼쳐져요.
- 바닥이나 물건을 누르면 가구를 돌아서 걸어가요 (사각형 가구 모서리를 경유하는 간단한 길찾기).

### 교무실

- NPC 3명(교무실무원, 교무부장님, 교감선생님)을 누르면 앞까지 걸어가서 대화창이 열려요.
- **간식 받기**: NPC마다 하루에 한 번(기기 날짜 자정 기준). 간식 20종, 희귀도 흔함 70%·특별함 25%·귀함 5%.
- **도감**: 모은 간식과 개수를 20칸 격자로 보여 줘요. **인사하기**: 가까운 NPC에게 고개 숙여 인사해요.
- 저장 위치: localStorage `getoffschool:snacks`(도감), `getoffschool:snackGiven`(오늘 받은 NPC)

### 교실 (4단계)

- 앞쪽 칠판에 **오늘의 한마디**(날짜마다 30개 중 하나), 교탁, 학생 책상 16세트, 사물함·게시판, 열린 창문, 내 업무 책상과 파쇄기.
- **업무 날리기**: 내 책상 위 기본 서류 20장. 날린 서류는 바로 다시 채워지지 않고, 날짜가 바뀌면(로컬 자정) 다시 20장이 쌓여요. "날리기" 버튼이나 서류 더미를 누르면 맨 위 한 장이 사라져요.
  - **서류 추가**: 마음에 걸리는 일을 직접 적어(14자까지, 하루 20장까지) 더미 맨 위에 올릴 수 있어요. 내가 올린 서류부터 날아가요. 다 날린 뒤에도 추가하면 다시 날릴 수 있어요.
- **앉기**: 학생 의자 16개나 내 업무 의자에 앉을 수 있어요.
  - 방식 4가지 + 아무거나: ✈️ 종이비행기(열린 창문 밖으로) · 🗂️ 파쇄기(띠 조각) · 🧽 칠판지우개(분필 글씨 슥슥) · 🎈 업무 풍선(팡! 색종이)
  - 고른 방식은 저장돼요. 연타하면 연속으로 날아가요. 한 장 연출은 약 1.25초.
  - 다 날리면 "오늘 업무 끝! 퇴근 준비 완료" + 칭호 **퇴근 준비 완료**.
- **카운터**: 상단 "오늘 날린 업무 N장 · 누적 M장". 읽고 쓰는 코드는 `src/services/counterService.ts` 한 곳뿐이에요.
  - 인터페이스: `getToday()`, `getTotal()`, `getSnapshot()`, `addOne()`, `subscribe()`, `reset()`
  - 지금은 localStorage 구현이고, 나중에 서버 공유 값으로 바꿀 때는 같은 인터페이스의 구현을 만들어 파일 맨 아래 `counterService` 한 줄만 바꾸면 돼요.
- 저장 위치: `getoffschool:pile:날짜`(남은 기본 서류), `getoffschool:custom:날짜`(내가 올린 서류), `getoffschool:flung:날짜`·`getoffschool:flungTotal`(카운터), `getoffschool:flingMethod`(방식)

### 벤치 "마음 띄우기" (5.5단계, 혼자 털기)

- 운동장 벤치(또는 잔디)에 앉으면 하단 버튼이 "마음 띄우기 / 일어나기"로 바뀌어요.
- 속마음을 100자 이내로 쓰고 "띄우기"를 누르면, 글이 구름이 되어 머리 위에 1.5초 보였다가 노을 하늘로 떠올라 사라져요(약 5초, 빛 입자 최대 30개).
- **쓴 글은 어디에도 저장하지 않아요.** 화면 메모리에만 잠깐 있다가 연출이 끝나면 지워져요. localStorage·sessionStorage·IndexedDB·쿠키·서버·콘솔 모두 사용하지 않고, 입력창은 자동완성·맞춤법 검사를 끕니다.
  - 저장하는 것은 "오늘 마음을 띄웠는지" 날짜 하나(`getoffschool:mind:floatedOn`)뿐. 이날은 교무실 NPC가 위로 대사(NPC별 5개)를 섞어 말해요.
- 전화번호·이메일 형식이 보이면 막지 않고 부드럽게 안내만 해요.
- 자기 위해를 암시하는 표현이 보이면 연출 뒤 따뜻한 안내 창(상담전화)을 보여 줘요. 감지 결과도 기록하지 않아요.
  - 감지 목록: `src/data/crisisWords.ts`
  - 문구·버튼 이름·상담전화 번호와 운영 정보: `src/data/mindFloat.ts` (`MIND_TEXT`, `CRISIS_CONTACT`, `CRISIS_TEXT`)

### 연구실 (5단계)

- 책장, 큰 작업 테이블(노트북·머그컵), 러그, 화분 + 상호작용 오브젝트 3개. 가까이 가면 테두리가 반짝이고 "눌러서 열기"가 떠요.
  - 📌 **메모보드**: 수업 아이디어와 꿀팁 · 반응 "써볼게요" · 포스트잇 색 4가지
  - 🧊 **냉장고**: 간식, 선물, 맛집 추천 · 반응 "맛있겠다" · 추천 이유 한 줄
  - 🖍️ **칠판**: 오늘의 한마디 · 반응 "나도 그래요" · 분필 글씨체
- 오브젝트나 하단 버튼을 누르면 앞까지 걸어가서 하단 시트 패널이 열려요. 최신순/공감 많은 순, 반응은 한 글에 한 번(다시 누르면 취소).
- **글 남기기 규칙**: 60자 이하(줄바꿈 없음), 완전 익명(무작위 이름 또는 "익명의 선생님"), 개인정보 안내 고정, 금지어·전화번호·이메일 차단(`src/data/bannedWords.ts`), 올린 뒤 30초 동안 연속 입력 제한, 내 글만 삭제. 글은 텍스트로만 그려요(HTML 해석 없음).
- 시드 글: 게시판마다 15개 (`src/data/boards.ts`), 반응 수 3~40.
- **데이터 접근**: 글·반응·삭제는 `src/services/boardService.ts` 하나로만 해요. 화면은 localStorage 를 직접 다루지 않아요.
  - 인터페이스: `getPosts(board, sort)`, `addPost(board, post)`, `toggleReaction(board, postId)`, `deleteMyPost(board, postId)`, `getCooldownRemaining()` — 모두 Promise
  - 6단계에서 같은 인터페이스의 Firebase 구현을 만들어 파일 맨 아래 `boardService` 한 줄만 바꾸면 돼요.
- 저장 위치: `getoffschool:board:posts:게시판`(내 글), `getoffschool:board:reacted`(내 반응), `getoffschool:board:lastPostAt`(연속 입력 제한), `getoffschool:guide:lab`(첫 안내)

### 개발용: 시간대 강제로 바꾸기

주소 뒤에 `?time=` 을 붙이면 돼요.

- `http://localhost:5173/?time=morning` (오전)
- `http://localhost:5173/?time=day` (낮)
- `http://localhost:5173/?time=evening` (저녁)
- `http://localhost:5173/?time=night` (밤)
- 숫자도 돼요: `?time=17.5` (오후 5시 30분)

### 개발용: 날짜 바꾸기 / 기록 초기화

- `?date=2026-11-02`: 오늘 날짜를 그 날짜로 강제 (하루 한 번 간식 제한 확인용)
- `?reset=1`: 도감·간식 기록, 교실 서류 더미(내가 올린 서류 포함), 날린 업무 카운터, 칭호, 연구실 데이터(내 글·반응·첫 안내), 오늘 마음을 띄웠는지 값을 지움 (바퀴 수는 그대로, 지운 뒤 주소에서 `reset` 은 저절로 빠져요)
- 함께 쓸 수도 있어요: `?time=night&date=2026-11-02`

## 배포 (GitHub Pages)

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 자동으로 빌드해서 GitHub Pages에 올립니다.
배포 주소: **https://gmeann.github.io/getoffschool/**

처음 한 번만 설정이 필요해요.

1. GitHub 레포 → **Settings → Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택
3. Actions 탭에서 실패한 실행이 있으면 **Re-run all jobs** (또는 **Run workflow**) 를 누르면 배포됩니다.

### 레포 이름(base 경로) 바꾸기

- 워크플로는 레포 이름을 자동으로 읽어서 `BASE_PATH=/<레포이름>/` 로 빌드해요. 레포 이름을 바꿔도 따로 고칠 것이 없어요.
- 직접 빌드할 때는 `vite.config.ts` 의 `REPO_NAME` 상수를 고치거나, 환경변수로 덮어쓰면 됩니다.

```bash
BASE_PATH=/my-repo/ npm run build
```

## 폴더 구조

```
src/
  components/  3D 물체(하늘, 바닥, 나무, 가로등, 벤치, 캐릭터, 카메라)와 HUD
  scenes/      장면 조립 (Playground = 운동장, Office = 교무실, Classroom = 교실, Lab = 연구실)
  services/    나중에 서버로 바꿀 수 있는 모듈 (counterService, boardService) + 글 검사(moderation)
  hooks/       내 캐릭터 상태·이동(playerStore), 바퀴 수 저장(lapStore), 시간대(useTimeOfDay)
  data/        공간 정의(scenes), NPC·대사, 간식, 업무 라벨·문구, 오늘의 한마디, 게시판 설정·시드 글, 금지어, 시간대 색, 배치·충돌 영역

```
